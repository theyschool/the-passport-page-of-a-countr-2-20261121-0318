An open passport spread of the Republic of Tidemark, a small tidal-island republic: a bilingual (English / Tidemaric) data page for holder Maris Vell of Lowater — engraved-style portrait, perforated number and a two-line machine-readable zone with ICAO check digits — facing a visas page whose Ostrevia and Keldan Union stamps tell one chronological 2022–2025 travel history inside the passport's 2021–2031 validity, down to the Keldan condition of admission: must depart before the tide. The image is rendered deterministically with PIL (`build_image.py`, all lettering in real DejaVu fonts); the program copies it to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
